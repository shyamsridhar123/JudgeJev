How to read these signals

Quality is a model-judged score, not human-certified accuracy. The frozen reference is compared with the most recent 20 completed requests in request order. Watch and alert thresholds are explicit operational rules, not statistical significance tests. Failed calls remain in the trace log and are excluded from score means. Ticket mix only measures the five labeled categories (plus Custom); it does not detect every kind of semantic drift. A fixed set of synthetic tickets demonstrates fault detection, not general production performance. The full ledger, rubric, reference membership, provider payloads, and timestamps are available in Export evidence.
